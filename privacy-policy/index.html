精造通软件造价评估 · 隐私政策

开发者：<于超> 版本：1.2.3 发布渠道：Microsoft Store

我们深知数据与信息安全对您的重要性。本政策说明本软件如何收集、使用、存储、共享及保护您的信息。多数情形下，您的业务数据仅保存在您的本机设备上，不会通过网络外发。仅当您主动启用相应可选功能（如在线大模型识别、参与模型改进）时，相关数据才会离开您的设备。

本软件经微软商城发布时，您还需遵守微软商城政策中关于隐私的要求。

注：本政策为通用说明。作为个人开发者，我们同样受《中华人民共和国个人信息保护法》等适用个人信息保护法律的约束。

一、适用范围

本政策适用于您通过 Windows 桌面端使用精造通软件造价评估的各类场景。使用本软件即视为您理解并同意本政策；若不同意，请停止使用本软件。

两类数据的根本区别：

  • 本地数据：默认仅存放在您设备上，不主动上传；
  • 网络数据：仅在您启用相应功能时发送（均有明确开关），发送范围与用途见下文。

二、我们处理的信息

2.1 本地存储的信息（不离开设备）

以下信息保存在您本机的应用数据目录或您指定的项目位置，除非您另行启用网络功能，否则不会外发：

  • 项目文件：您的模块清单、功能点计数、NESMA 规模估算、工作量与费用估算结果、文档解析结果、费用构成配置等业务数据；
  • 崩溃恢复快照：用于异常退出后恢复未保存内容的安全快照；
  • 设置信息：界面偏好、主题外观、表格字号、最近打开项目、AI 提供方配置等；
  • 许可信息：您的激活/订阅状态相关数据（敏感项经加密保护）；
  • 本地训练样本：您在软件内「采纳/修正/导入/不采纳」等功能点识别建议、以及文档解析修正操作所产生的样本记录，默认仅存本机本地训练数据，不自动上传。

2.2 授权校验相关的信息（联网）

为履行《最终用户协议》中的订阅、试用与席位管理，本软件会定期连接授权服务端并传输：

  • 硬件指纹（HWID）：基于设备标识（如机器唯一标识、系统盘卷序列号）经哈希算法计算得到的不可逆指纹，用于登记试用、识别设备、管控席位数量；
  • 激活/校验请求：激活码相关标识、校验状态与时间戳；
  • 结果：授权状态反馈（试用/已授权/离线宽限/已过期/已吊销等）。

此类信息仅用于授权与防滥用，服务端仅保存不可逆的哈希值，不存储可明文还原的设备标识。

2.3 在线大模型识别（可选功能，需您主动启用）

  • 触发方式：您在规模估算页点击「在线大模型识别」按钮时，首次会对该文件弹窗征得同意，否则仅可使用离线本地模型；
  • 发送内容：为获得功能点识别建议，软件会将相关功能描述文本发送至第三方大模型服务提供商（默认 DeepSeek / 可配置的 OpenAI 兼容接口，如 qwen、glm、本地 Ollama 等）；
  • 用途：仅用于生成功能类别/复杂度/新增或修改等识别建议，软件返回结果后供您自行采纳、修正或不采纳；
  • 第三方：该场景向您选定的大模型服务商披露描述文本，适用该服务商的条款与隐私政策。如您未启用，则不会发送任何描述文本。

2.4 参与模型改进的样本回传（可选功能，需您主动勾选）

  • 触发方式：在每个项目文件的确认弹窗中勾选「参与模型改进」，以及/或保留全局「参与模型改进」设置；
  • 门槛：勾选即表示同意回传，不要求您同时启用在线识别；
  • 发送内容：
    • 功能点样本：您已确认的计数项（采纳/修正/导入，以及「不采纳但描述非空」的记录），含描述、识别类别与来源信息；
    • 文档解析修正样本：您对文档标题层级（Heading:n、Exclude 等）所做的修正；
  • 用途：用于改进功能点识别与文档解析模型；样本条目以不可逆哈希作为标识做幂等去重；
  • 不发送：未经您确认计数项、您未勾选「参与模型改进」时的数据，不参与回传。

2.5 崩溃与诊断（可选）

在您开启诊断模式时，可能收集本机运行日志、崩溃信息（含出错时的项目路径与未保存状态标识）用于故障排查。日志默认保存在本机日志目录，仅按需用于支持。

三、信息的使用

我们仅在本政策所述范围内使用上述信息：提供核心功能、履行授权与订阅管理、改进模型与产品质量、保障系统安全与稳定性、满足合规要求。我们不会将您的业务数据用于营销、出售或租借给无关第三方。

四、第三方共享

除下列情形外，我们不对第三方披露您的信息：

  1. 您选定的大模型服务商（仅在线识别场景，见 2.3）；
  2. 我们自身运营的服务端（激活/授权校验、样本回传，见 2.2 / 2.4）；
  3. 法律法规要求、司法/行政机关依法要求必须披露的情形；
  4. 为保护我们或第三方合法权益所必需的其他情形。

所有数据传输均通过加密通道（HTTPS/TLS）进行。

五、存储与安全

  • 本地数据：存储于您设备本机；敏感项（如许可刷新令牌、部分设置）经加密保护（DPAPI 加密）；文件写入采用临时文件+原子替换以避免损坏；可配置保存前自动备份。
  • 网络数据：经加密传输；服务端对关键标识仅存不可逆哈希（减少泄露风险）。
  • 我们采取合理的管理、技术与物理措施保护信息安全；但请理解，任何网络环境下都无法保证绝对安全。

六、您的权利与选择

  1. 不启用即可不外发：不点击「在线大模型识别」即不会发送描述文本；不勾选「参与模型改进」即不会回传样本；这些开关自由可逆。
  2. 离线模式：使用本地模型识别、手动编辑时，完全不联网。
  3. 本地数据控制：您可随时在设置或文件管理中查看、导出、备份或删除本机本地数据（.fpca、设置、本地样本、日志、恢复快照等）。
  4. 删除样本/停止回传：关闭「参与模型改进」后不再新增回传；您可以要求删除已回传的样本（见第九条联系渠道）。
  5. 撤回同意：您可以随时撤回在线识别与样本回传的同意开关，撤回不影响撤回前已处理行为的合法性。
  6. 依照适用法律（如《个人信息保护法》），您对于您的个人信息享有查询、更正、删除、撤回同意、注销及投诉举报等权利，可通过第九条渠道行使。

七、未成年人保护

本软件为专业工程造价评估工具，主要面向具备相应专业能力的企业/从业人员。我们不会主动收集未成年人的个人信息；若您是未成年人，请在监护人指导下使用。

我们可能依据业务功能调整与法律法规要求不时更新本政策，更新后将在本页面或软件内公布。重大变更将尽量以显著方式通知。您继续使用本软件即视为接受更新后的政策。
